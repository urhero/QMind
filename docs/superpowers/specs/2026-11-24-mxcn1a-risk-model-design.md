## 3. China A 특유 처리

### 3.1 거래정지
- 휴장일 = 그날 A주 보통주의 `prcstd=5` 비율 ≥ 90%. 실측 휴장일은 정확히 100% 이고, 대량 정지가 가장 심했던 2015-07-09 도 51.4% 라 90% 로 깨끗이 갈린다.
  **"과반이 거래한 날 = 거래일" 같은 다수결 기준은 쓰지 않는다** — 2015-07-09 이 휴장으로 빠진다.
- 거래일의 `prcstd=5` = 거래정지 → 수익률 결측.
- 정지가 풀린 첫날 수익률은 정지 기간 누적분이라 **회귀에서 뺀다** (직전 **거래일**이 정지였던 날). 휴장 다음 날은 정지 재개가 아니다. 판정하려면 `daily_prices(traded_only=False)` 로 읽어 거래일 달력과 맞춘다.
- 옵티마이저: 정지 종목은 **비중 고정** (매매 불가). 목표에는 남긴다. 백테스트 손익에는 재개일 수익(정지 기간 누적분)을 그대로 넣는다.

### 3.2 가격제한 (상하한가) — 규정표 없이 데이터로 판정
- **고정일 = 거래일이고 종가가 제한가 후보와 같고, 상한이면 종가 = 고가, 하한이면 종가 = 저가.**
  제한가 후보 = round(기준가 × (1 ± L), 0.01위안), L ∈ {5%, 10%, 20%}, 기준가 = 전일 종가 × 분할 조정(`ajexdi` 비율). 시장·ST 여부·시점마다 다른 제한폭을 몰라도 잡힌다 (저가주 반올림도 그대로 맞음: 0.23 → 상한 0.24).
  **장중에 거래되다 종가에 잠긴 날(고가 ≠ 저가)도 고정이다** — 종가(MOC) 매매에서 상한 종가는 매수 대기만, 하한 종가는 매도 대기만 쌓여 그 방향은 체결되지 않는다.
  실측 (2026-11-24, 그날 총시총 상위 600 A주): 2015-07-09 상한 종가 555건 중 일자판(고가 = 저가) 0건, 2015-06-30(월말) 상한 종가 91건 vs 일자판 1건, 2016-01-04·07 하한 종가 각 ~200건 vs 일자판 1~2건, 평시(2025-06 말) 0~7건. 예전 규칙(고가 = 저가 & |수익률| ≥ 4%)은 대형주 고정을 대부분 놓친다.
  고가·저가는 `v_px_d` 의 `px_high/px_low` 를 써도 된다 (A주는 CIQ 값 = Compustat 값, 2015-07-09·2025-06-30 전 종목 일치).
  한계 (M1 에서 빈도 리포트): 현금배당 배당락일은 거래소 기준가가 배당만큼 낮아 후보가가 어긋나 놓친다 (분할·무상증자는 `ajexdi` 로 반영). ±20% 종목이 정확히 ±5%·±10% 가격에서 고가(저가) 마감하면 고정으로 오판.
- **한쪽만 막는다:** 상한가 고정 = 매수 불가 (w ≤ w₀), 하한가 고정 = 매도 불가 (w ≥ w₀). 프로덕션은 그날 판정, 백테스트는 월말 리밸런싱일이 고정일이면 그 방향 매매를 그 달 막는다 (다음 거래일로 미루지 않는 단순화).
- 리스크 모델 회귀에서는 제외하지 않는다 (가격이 실제로 그만큼 움직임).
- 규정 변경 이력(§9 검증 5 출처 — 주판 ST ±5%→±10% 2026-07-06 등)은 ST 가격 보정(`st_repair.py`, 2026-07-06 이전만)과 정리매매 기간(§3.5)에만 쓴다.

### 3.3 BM 비중과 시총 — 133333 (CNY 라인 DIF) · 718708 (CNH 라인 FIF)
- **리스크 모델은 유동비율을 쓰지 않는다.** 시총(회귀 1차 가중 √시총, 업종 제약 시총가중, 스타일 표준화 시총가중 평균)은 ESTU 전체를 총시총 `prccd × cshoc` 로 한다.
  DIF 는 BM 종목에만 있어서 (A주 총시총의 66.5%) BM 종목은 DIF 시총, 나머지는 총시총으로 섞으면 BM 밖 종목이 상대적으로 ~2배 크게 잡힌다 (DIF 평균 0.47).
  BM 비중은 `msci_idx_wgt` 를 그대로 읽으므로 유동비율을 다시 만들 일이 없다. 아래는 그 비중이 맞는지 확인한 기록이다.
- **총시총이 예측 위험에 주는 영향은 1차 회귀 가중뿐이다.** 업종 제약(시총가중 합 0)과 스타일 표준화 중심(시총가중 평균 0)은 식별 조건이라, 다른 가중을 써도 시장 절편과 업종·스타일 팩터 사이에서 상수만큼 맞바뀔 뿐 적합값·잔차·어떤 포트의 예측 위험도 같다 (공분산 추정이 선형인 한 — 변동성 국면 조정 같은 비선형 보정은 예외). 회귀 2차 가중은 잔차분산 역수라 시총과 무관하다.
  그래서 국유 대주주 지분이 큰 종목을 총시총으로 무겁게 잡는 것은 1차 회귀 효율 문제이고, B/C 바이어스·Q 로 본다. xf_target 에 ESTU 전체에 쓸 유동주식 테이블은 없다 (테이블 이름 float·Own·Holder 검색 0건, 2026-11-24).
- **133333 (MXCN1A, China A Onshore)** = Domestic 플래그 + DIF. 같은 회사가 CNY(본토) 라인과 CNH(Stock Connect) 라인 두 개로 들어 있고, CNH 라인은 MSCI China A·EM 용이다.
  - 실측 (2026-11-20): CN·A주·CNY·`family_std_dom_flag=1` → 561종목 = `INDEX_REPORT` 133333 종목 수. `price × closing_number_of_shares × domestic_inclusion_factor` 로 만든 비중이 `msci_idx_wgt` 와 561/561 일치 (최대 차이 5.6e-17). CNY 라인의 FIF ≠ DIF 가 84% (FIF 평균 0.28, DIF 0.47).
  - 다른 시점 재현: 2018-06-29 676/676, 2022-12-30 813/813 일치 (FIF 로 바꾸면 종목 비중 최대 1~2%p 어긋남). 2025-06-30 은 당일 칸으로 최대 3bp 차이 → **다음날 칸**(`*_next_day`)으로 559/559 일치 (그날 주식 수·DIF 가 바뀐 종목 2개). `msci_idx_wgt` 의 `basis='N'` 이 다음날 기준이기 때문.
  - 재현 규칙: CNY 라인 DIF + 다음날 칸. CNH 라인이나 FIF 를 쓰면 유동비율이 절반 이하로 잡힌다.
- **718708 (China A)** = CN·표준 플래그·**가격통화 CNH (Stock Connect 라인)만**·FIF, `std_IIF` 미적용 (방법론 각주). bbg 구성 파일 415종목과 비중 차 5e-7%p.
  - 공식 이력은 2019-12-02(일별)·2019-12(월간)부터. 그 전 `718708_bf` 는 규칙 시뮬레이션이다: 2018-06~2019-11 실제 지수는 대형주만이었지만 bf 는 2019-11-26 이후 방식대로 대+중형을 담고 (사용자 결정 2026-10-30, 실제 대형주의 98.2% 포함), 2018-06 전은 지수 자체가 없었다 → 성과는 2019-12 전후를 나눠 리포트.
  - 718708 ⊂ 133333 (2026-10 기준 빠진 146종목은 Connect 라인이 없음). 외국인 한도 소진(다음날 FIF 0) 종목은 비중 0 으로 빠진다 → 거래 유니버스 밖이라 신규 매수 불가 (§5).

### 3.4 ST·*ST
- 출처: CNINFO 공시 검색(`/new/hisAnnouncement/query`)에서 2002~2026 "风险警示"·"特别处理" 공시 11,098건 → 제목으로 지정·해제 판정 → 시행일은 PDF 본문("起始日"·"复牌"·"自…起", 75%), 없으면 공시 다음 거래일.
- 공시가 빠진 33구간은 주판 가격제한 패턴으로 시작·종료일 보정 (`repair` 열).
- 품질 (주판, ±5% 고정 상하한가일 중 ST 구간 밖 비율 = 누락 추정): 2015 이후 0~5%, 2011~2014 8~12%, **2005~2010 13~36%**. 현재 시점 대조(CNINFO 현재 약칭): 상장폐지 정리 종목 제외 불일치 26/~5,400.
- 주의:
  - **CNINFO 의 공시 당시 약칭(`secName`)은 현재 이름이 섞여 있어 상태 판정에 쓰면 안 된다.**
  - `end` 비어 있음 = 현재 지정 중 **또는 지정 중 상장폐지**. Compustat 폐지일로 자른다.
  - `start` 비어 있음 71구간 = 전부 주판, 해제일 2002~2009. 수집 시작(2002) 전 지정분이라 2010 이후 구간에는 영향 없음.
  - `code=000000` 1행 (2008-04-29~, 공시에 종목 코드가 비어 있던 江苏申龙·S*ST湖科) 은 이관 때 뺀다. 2010 전이라 추정 구간에 영향 없음. 같은 종목 구간 겹침 0 (2026-11-24 확인).
  - 코드 기준이므로 gvkeyiid 에 붙일 때는 §2 "종목 코드" 규칙(그 날짜에 가격이 있는 키)으로. MSCI 종목에는 `china_stock_code` 로 바로 붙는다.
  - BM(133333) 에 ST 가 들어 있는 경우는 드물다: 2019-06-28 1종목(지정 9일 후, 다음 정기변경 전), 2023-06-30·2026-11-20 0종목.
- 수집·재구성·검증 스크립트: `research/st_history/` (사용법 `README.md`). Windows 에서 CNINFO 접속 여부는 미확인.
  프로덕션(M7)은 리밸런싱 전마다 갱신해야 한다. CNINFO 가 안 되면 대체 = 현재 약칭의 ST·*ST 접두 (bbg 등). **현재 시점 판정에만** 쓴다 — 과거 구간을 약칭으로 만들지 않는다 (위 주의 1).

### 3.5 정리매매·신규상장
- 정리매매: 판정에 약칭("退")을 쓰지 않는다 (§7 #6). **진짜 폐지 종목(§2 상장폐지, 우회상장 키 교체 제외)의 마지막 거래일 이전 30거래일 (2020-12 개정 이후 폐지분은 15거래일)을 ESTU 에서 뺀다.**
  대부분은 이미 ST 구간 안에 있다 (`end` 빈 구간 = 폐지일까지). 정리매매 첫날은 가격제한 없음.
  - 한계: 정리매매 없이 폐지되는 가격 요건 폐지(20거래일 연속 1위안 미만)는 이 규칙이 마지막 15거래일을 미리 빼는 셈이라 ESTU 에 약한 사후 정보가 들어간다. 해당 종목은 저가·저유동이라 회귀 영향은 무시할 수준으로 본다.
  - 이 규칙은 **거래 쪽(백테스트)에는 쓰지 않는다** — 미리 빼면 폐지 손실을 피하는 생존편향이 된다. 거래 쪽은 BM 구성과 ST 구간(공시 시점 정보)만 따른다.
- 백테스트 보유 중 폐지: 거래 유니버스가 BM 구성종목 기준이라 (MSCI 가 ST·장기정지 종목을 먼저 뺀다) 드물 것으로 보고, **마지막 거래가 대비 -100% 로 계상** (보수적 기본값). 실제 건수를 M5 에서 리포트하고, 의미 있는 수면 폐지 후 거래 가격(退市板块)으로 바꾼다.
- 신규상장: 상장 후 **6개월(약 120거래일) 미만은 ESTU 제외**. 노출은 본설계 §5.1 "노출을 못 구하는 종목" 규칙.
  상장일은 6자리 코드의 첫 가격일이다 — 우회상장·합병 키 교체는 새 상장이 아니다 (거래가 1~3일 간격으로 이어짐, §2 종목 코드). 키 교체일 수익률(옛 키 끝 종가 → 새 키 첫 종가)은 정지 재개일처럼 회귀에서 빼고, 백테스트 보유 중 교체는 그 가격 비율을 손익에 넣고 건수를 M5 에 리포트.

### 3.6 ESTU (D3 = b)
A주 보통주 중 월말 기준: ST·*ST·정리매매(§3.5) 아님, 상장 120거래일 이상, 월말 거래정지 아님, 직전 60거래일 거래일 비율 ≥ 80%, 유동성(일평균 거래대금) 하위 10% 제외, **누적 총시총 상위 X% 밖(초소형주) 제외**.
X 는 2021-05 ESTU 가 bbg MAC3 China (~2,900, 백서 §1B "micro-cap·저유동 제외") 근처가 되도록 M1 에서 한 번 정해 고정한다 (성과로 고르지 않음). 초소형주가 많으면 Size·Mid-Cap 이 "대형 vs 중형" 대신 "중형 vs 초소형" 을 재고, 2024-01~02 초소형주 급락 같은 BM 밖 충격이 모델에 섞인다. 컷 없는 변형은 M4 에서 Q 로 비교.
그 달 일별 회귀 표본 = ESTU ∩ 그날 수익률 있음 ∩ 정지 재개일 아님.
회귀 가중은 본설계 §5.1 2-pass 그대로 (1차 √총시총 → 잔차분산 EWMA → 2차 역수). 바이어스 통계로 가중 방식을 고르지 않는다 (본설계 3차 검토: 빌더 재량으로 두면 결과가 달라지는 선택).
규모는 M1 에서 실측 (시총 컷 전 3,000~4,500 예상).

## 4. 리스크 모델 v1 (China A, 두 BM 공용)

### 4.1 통계 모델 B (M2, C 이전의 기준 모델)
- 입력: ESTU(§3.6) 일별 총수익률만. 재무·분류 데이터 불필요 → M1 의 가격 부분만 끝나면 바로 만들 수 있다.
- **PCA 하나:** 월말마다 직전 창(EWMA 가중, 반감기는 C 의 상관 반감기와 같게)에서 상위 30 성분, 나머지는 종목별 고유분산.
  X = 성분 적재값, F = 성분 공분산, Δ = 고유분산 → C 와 같은 인터페이스라 옵티마이저의 팩터 형태 SOCP 에 그대로 꽂힌다.
  (Ledoit-Wolf 수축 표본공분산은 뺐다: N×N 밀집 행렬이라 X·F·Δ 로 안 나뉘어 옵티마이저 형태와 맞지 않고, N(3,000~4,500) > T 다.)
- 추정 집합 = 그 월말 ESTU 중 창 안 관측 ≥ 80%. 결측(정지일·재개일)은 종목 평균을 뺀 뒤 0 으로 둔다.
  한계: 정지가 잦은 종목의 분산이 조금 낮게 잡히고, 2015 하반기처럼 절반이 정지하면 "같이 정지한 종목" 이 가짜 성분으로 잡힐 수 있다 → M2 에서 2015 하반기 창의 상위 성분 적재값과 종목별 정지 빈도의 상관을 본다. 바이어스 통계에 걸리면 EM 대치로 바꾼다.
- 계산: 가중 수익률 행렬(T×N)을 바로 SVD 한다 (N×N 공분산을 만들지 않음).
- 추정 집합 밖 종목 (BM 신규편입·이력 짧은 종목): 관측 ≥ 60거래일이면 성분 수익률에 시계열 회귀해 X·Δ, 그보다 짧으면 X = 추정 집합 시총가중 평균 적재값, Δ = 추정 집합 고유분산 중앙값.
  이 규칙이 없으면 옵티마이저가 그 종목을 다룰 수 없다.
- 미래 정보 차단은 C 와 같다 (월말 t 의 모델은 t 까지의 수익률만).
- 업종·스타일 중립 제약은 B 로는 못 건다 (성분에 경제적 의미가 없음) → M3 에서는 D1(a) 목표 추종과 TE 계산만 확인하고, 노출 제약은 C 로 바꾼 뒤 켠다.
- 한계: TE 0.6% 실운용에는 쓰지 않는다 (2026-11-24 논의 — regime 변화 때 예측이 흔들림).

## 7. 함정 목록 (2026-11-24 실측으로 확인된 것)

1. `sec_idcurrent` 의 A주 `TIC` 는 비어 있다 → 6자리 코드는 `ciqGvkeyIID` → `ciqTradingItem.tickerSymbol`.
2. Compustat `co_filedate` 는 A주 공시일이 거의 없다 → 재무 PIT 는 Capital IQ `filingDate`.
3. Capital IQ `ciqPriceEquity` 는 거래정지일 행이 없다 → 정지를 놓친다.
4. MSCIDB 에서 133333 비중을 CNH 라인·FIF 로 재현하면 유동비율이 틀린다 → CNY 라인 DIF (718708 은 반대로 CNH 라인 FIF).
5. MSCIDB `SECURITY_REPORT` 는 대·중형 표준 유니버스(`D15E_RIF`)만 적재 — A주 소형주 없음.
6. CNINFO `secName` 은 공시 당시 약칭이 아닐 수 있다 (현재 이름 혼입) → 약칭으로 ST·정리매매를 판정하지 않는다.
7. ST 가격제한폭이 2026-07-06 부터 ±10% → 가격제한으로 ST 를 추정하는 방법은 그 이후 불가. 상하한가 고정 판정은 규정과 무관한 데이터 규칙으로 (§3.2).
8. xf_target 대형 테이블 전체 로딩 금지 (연 단위 분할).
9. DB 계정·권한 정보는 이 문서(공개 리포)에 적지 않는다. 접속은 `.env` 의 기존 키만 쓴다 (`SERVER_NAME2`·`*_NAME2` = xf_target, `SERVER_NAME3`·`*_NAME3` = MSCIDB). `config.py` 는 아직 `*_NAME3` 를 읽지 않는다 (M0/M1 에서 추가). `.env` 는 수정하지 않는다.
10. `prcstd=5` 에는 휴장일 행이 섞여 있다 → 정지 판정 전에 거래일 달력부터 만든다 (§3.1).
11. Compustat `secstat='I'` 는 진짜 폐지와 우회상장 키 교체를 구분하지 않는다 → 6자리 코드 연속성으로 구분.
12. `msci_idx_wgt` (`basis='N'`) 를 재현할 때는 `*_next_day` 칸.
13. `risk_model` 브랜치에는 `main` 의 direct-load·일별 읽기 코드와 본설계 3차 검토가 없다 (M0). 718708 유니버스는 `718708` 브랜치에만 있다.
14. 다수결 거래일 달력 금지: 2015-07-09 A주 51.4% 가 정지라 "과반 거래" 기준이면 휴장으로 빠진다. 휴장 = `prcstd=5` ≥ 90% (실제 휴장은 100%).
15. `daily_prices()` 기본값(`traded_only=True`)은 휴장·정지 행을 다 빼서 정지 재개일을 못 가린다 → `False` 로 읽고 달력과 맞춘다.
16. `v_px_d` 의 trfd 는 as-of 조인 (`thrudate` 무시). 기간 조인 + "없으면 1" 로 다시 짜면 기간 사이 빈 칸에서 가짜 점프.
17. ClariFI MXCN1A 는 2025-06 종목 마스터 정지 이후 BM 비중 ~2.8% 누락, 2026-09 에는 5종목 행 자체가 없음 → 원재료는 AFL Intl.
18. DIF(BM 종목만)와 총주식(나머지)을 한 시총 칸에 섞지 말 것 → BM 밖 종목이 ~2배 커진다.
19. ESTU 용 정리매매 사전 제외(§3.5)를 백테스트 거래 쪽에 쓰면 폐지 손실을 피하는 생존편향.
20. ST 파일 `code=000000` 행은 공시 코드 누락분 → 이관 때 제외.
21. `exchg IN (249,250)` + `tpci='0'` 에는 B주(USD·HKD)와 펀드 코드(5xxxxx)가 들어 있다 → `curcdd='CNY'` + 코드 0·3·6.
22. 가격제한 고정을 "고가 = 저가" 로만 잡으면 대형주 고정의 대부분(종가 잠김)을 놓친다 → 제한가 후보 일치 (§3.2).
23. 같은 코드에 두 키가 같은 날 거래된 날이 있다 → 하루 한 코드 한 키.
24. 우회상장·합병 키 교체를 신규상장으로 보면 거래가 이어지는 종목을 120거래일 빼고 시계열을 끊는다 → 코드로 잇는다.
25. 운용 BM(`NU…`, net)이나 가격수익률(`mreturn`)을 총수익 AP 와 바로 비교하지 말 것 → 같은 총수익으로 합성한 BM (M5).
