# 스무딩 비용-인지 6-way 비교: 선정 히스테리시스 / 스타일별 step

- 실행일: 2026-06-12
- 스크립트: `scripts/run_smoothing_cost_experiment.py` (Git `d2aec19`, 메커니즘 `a454b6b`)
- 백테스트 기간: `2009-12-31` ~ `2026-05-31` (OOS 162개월)
- 공통 파라미터: min_is=36, factor_rebal=6, **weight_rebal=1**(월간, production cadence), top=50, ranking=**tstat**, cluster_dedup(n=18)
- 산출물: `output/experiments/smoothing_cost_summary.csv` (+ config 별 월별 `smoothing_cost_monthly_*.csv`)

## 0. 동기

무스무딩 디폴트 결정([absolute_step_attribution_20260607.md](absolute_step_attribution_20260607.md))은
**팩터단 전환비용 0 가정**의 OOS 비교에 기반했다. 그러나 팩터 비중 변경은 실제로는
종목 매매를 유발한다 — 백테스트 gross 수익률에는 팩터 내부 종목 리밸런싱 30bp 만
차감되어 있고, 팩터 간 비중 이동 비용은 빠져 있다 (research.md §6.1).

본 실험은 (1) 그 비용의 실제 크기를 계측하고, (2) 비중 스무딩의 대안으로
**선정 단계 개입(히스테리시스)** 과 **스타일별 step 차등** 두 축을 함께 비교한다.

## 1. 방법론

- **실런 기반**: 6개 config 를 모두 실제 walk-forward 엔진으로 실행. 월별 배포
  가중치를 `deploy_weights` 로 재구성, 재구성 수익률 == 엔진 `oos_return`
  검증 (**최대 오차 1e-17**, 전 config).
- **전환 턴오버**: `T_t = sum_f |w_t[f] - w_{t-1}[f]|` (배포 가중치 L1, 첫 월 제외,
  가용 0 월은 포지션 유지로 간주).
- **비용 모델**: `net_t = gross_t - (bps/1e4) x mult x T_t`.
  팩터 비중 1단위 = 종목 gross 2 (롱1+숏1) 이므로 `mult=2.0` 은 바스켓 중첩
  상계가 전혀 없는 상한, `mult=1.0` 은 상계 ~50% 가정. 시나리오:
  30bp x1 / **30bp x2 (기준)** / 50bp x2 (스트레스). 팩터 내부 30bp 와 비중첩.
- **Tier 1 공유 캐시**: 규칙학습/수익률 사전계산은 스무딩 파라미터와 무관하므로
  config 간 재사용 (비캐시 동일성 test-mode 검증). 총 런타임 47분.
- **엔진 변경 주의**: 본 실험은 `a454b6b` 이후 엔진 기준 — (a) Tier 1 에서
  스무딩 prev 를 carry (기존: 6개월마다 리셋 -> production 과 불일치했음),
  (b) step_smooth 정규화 2계층화. 따라서 absstep gross(1.611%)는 기존 노트
  (1.663%, 리셋 있는 구버전 엔진)와 직접 비교 불가. 무스무딩은 두 변경의
  영향이 없어 기존 노트와 **정확히 일치** (CAGR 1.7366%) — 방법론 앵커.

## 2. 비교 메커니즘

| 축 | 정의 | 구현 |
|----|------|------|
| 절대스텝 스무딩 | 배포 비중이 목표쪽으로 최대 1%p/월 이동 | `turnover_step=0.01, deadband=0.003` |
| 스타일별 step | 타이밍 lag 손실이 집중된 빠른 신호 스타일(Price Momentum, Analyst Expectations)만 step=1.0(즉시), 나머지 1%p/월 | `style_step_overrides` |
| 선정 히스테리시스 | 챌린저가 직전 보유 팩터를 rank_score(tstat) 격차 margin 이상 이겨야 교체. 노이즈성 rank flip-flop 교체를 차단, 큰 신호 변화는 즉시 반영 | `selection_hysteresis=0.25 / 0.50` |

## 4. 해석

1. **무비용 가정이 가린 비용은 전략 수익률보다 크다.** 월간 cadence 무스무딩의
   전환 턴오버는 월 0.328 (팩터 비중의 33%가 매월 재배치, 선정 교체 ~6쌍/월).
   30bp x2 기준 연 -2.36%p — gross 1.74% 를 **net -0.64%** 로 뒤집는다.
   현 디폴트는 비용 인지 기준으로 6개 config 중 최하위.

2. **비중 스무딩은 절반의 해법.** absstep/style_step 은 비중 이동만 늦출 뿐
   선정 churn(8.4~9.4개/월)이 그대로라 누적 턴오버가 높고(0.215~0.247),
   타이밍 lag 로 gross 도 깎인다. style_step 은 기여도 노트의 가설대로
   absstep 의 gross 손실을 회복하지만(1.77% vs 1.61%, Sharpe 0.885)
   히스테리시스에는 미치지 못한다.

3. **히스테리시스는 턴오버와 gross 를 동시에 개선한다 (-64% / +0.6~0.74%p).**
   비용 절감만 기대했으나 gross 자체가 올랐다 — 경계부 팩터 교체가 대부분
   노이즈라는 기존 진단(IS-OOS Rank Corr 0.14, OOS Percentile ~47%)과 정합.
   순위 뒤집힘을 따라가는 거래는 비용을 내고 노이즈를 사는 행위였다.

4. **최적 조합은 hyst025_style** (히스테리시스로 선정 churn 차단 + 잔여 비중
   이동은 느린 스타일만 스텝 제한): 턴오버 0.093 (nosmooth 의 28%),
   net 30bp x2 CAGR 1.72%, 모든 비용 시나리오에서 1위.
   단순성을 우선하면 hyst_050 단독도 근접 (1.62%).

5. **트레이드오프**: 히스테리시스는 gross MDD 를 -2.3% -> -4.3% 로 깊게 한다
   (신호 적응 지연). 그러나 net MDD 는 -5.1~-5.5% vs nosmooth -13.5% 로
   압도적 우위 — 실거래 기준 위험도 히스테리시스가 낮다.

## 5. 한계 / 후속

- **사후 설계 위험**: 히스테리시스는 이 데이터의 진단(랭크 노이즈)에서 설계되어
  같은 데이터로 검증됐다. margin 민감도(0.10/0.75 추가 grid), 기간별 일관성으로
  부분 보강했으나, production 적용 전 cadence(wr=3)·min_is 변형 확인 권장.
- **비용 모델은 근사**: mult 1~2 범위를 제시했고 순위는 전 구간 불변이지만,
  실제 mult 는 bbg 체결 데이터로 캘리브레이션 가능 (전환 월의 실측 종목
  턴오버 / 팩터 L1).
- ~~production 미배선~~ -> **2026-06-12 production 적용 완료** (§7 후기 참조).
- 디폴트 `turnover_step=1.0` (무스무딩) 은 유지 — 비중 스무딩 축은 개선이 작아
  히스테리시스 단독 적용 (스타일별 step 은 엔진 실험 옵션으로 보존).

## 7. 후기: production 적용 (2026-06-12)

`selection_hysteresis=0.5` 를 production `mp` 에 배선·적용했다.

- incumbents 출처: 직전 `factor_styles_{date}.csv` 의 **raw_weight > 0**
  (= 직전 선정 집합). 배포 가중치 키가 아닌 raw 기준 — 스무딩 청산 중인
  탈락 factor 가 incumbent 로 잘못 잡히는 것을 방지 (`load_prev_selection`).
- margin=0 배선 검증: 단위테스트 266 + mp test/실데이터 **byte-identical**.
- margin=0.5 첫 적용 (2026-05-31 재생성, incumbents=2026-04-30 선정 38개):
  월간 선정 churn **21개 -> 13개** (4 swap 되돌림). 보호된 4개는 전부
  챌린저보다 tstat 이 높았다 — Rev3MFY2C(5.04) vs 5DVolSig(0.20),
  OCFEV(2.71) vs Alpha18M6MPChg(0.99), Alpha60M(2.43) vs SGAToSales(1.39),
  PM1M(2.21) vs NCAP(1.45). margin 없이 탈락했던 원인은 점수가 아니라
  **클러스터 자리싸움** (같은 클러스터에 더 강한 factor 3개) — 히스테리시스가
  cluster reshuffle 로 버려지던 고득점 incumbent 를 지키는 효과도 있음을 확인.

## 8. 동결 극한 grid: 선정 업데이트의 한계 가치 측정

margin 을 극한까지 올려 "월간 재선정이 도대체 얼마나 기여하는가"를 측정했다.
margin=999 는 사실상 동결 — 최초 선정을 유지하고, 후보군에서 강제 탈락한
factor 만 당시 최고 점수 factor 로 교체한다.

| margin | gross CAGR | gross Sharpe | 턴오버(L1/월) | 선정churn(개/월) | net 30bp x2 CAGR | net Sharpe |
|---|---|---|---|---|---|---|
| 0 (무, 현행이었던 것) | 1.74% | 0.850 | 0.328 | 11.7 | -0.64% | -0.30 |
| 0.10 | 2.25% | 0.810 | 0.130 | 3.1 | 1.30% | 0.48 |
| 0.25 | 2.36% | 0.826 | 0.126 | 3.0 | 1.43% | 0.51 |
| 0.50 (production 적용값) | 2.48% | 0.856 | 0.118 | 2.6 | 1.62% | 0.57 |
| 0.75 | 2.51% | 0.881 | 0.108 | 2.3 | 1.72% | 0.61 |
| 1.00 | 2.57% | 0.890 | 0.103 | 2.2 | 1.81% | 0.64 |
| 1.50 | 2.56% | 0.896 | 0.100 | 2.0 | 1.83% | 0.65 |
| 999 (동결) | 2.52% | 0.888 | 0.095 | 1.9 | 1.82% | 0.65 |

**해석:**

1. **곡선은 margin ~1.0 에서 플래토에 도달하고, 완전 동결도 동급이다**
   (gross 2.52~2.57%, net 1.81~1.83%). 즉 **강제 탈락 교체를 넘어서는 월간
   재선정의 한계 가치는 사실상 0** — IS-OOS Rank Corr 0.14 진단의 최종 확인.
   가치가 있는 것은 (a) 최초 선정 (funnel 의 EW_Top50 > EW_All), (b) 데이터
   유효성을 잃은 factor 의 강제 퇴출, (c) 선정 시점의 cluster/style 구조이지,
   순위 변동을 따라가는 월간 교체가 아니다.
2. churn 의 구조적 하한은 ~1.9개/월 (동결에서도 발생) — 규칙 갱신/zero-filter
   로 후보군에서 사라지는 factor 의 강제 교체분.
3. gross MDD 는 1.0/1.5/999 에서 동일 (-4.42%) — drawdown 은 교체 정책이 아니라
   보유 포트폴리오 자체에서 나온다.
4. **production 함의**: 적용값 0.5 는 플래토 직전 (net 1.62% vs 플래토 1.81~1.83%).
   0.75~1.5 로 올리면 ~0.2%p/년 추가 여지가 있으나, 같은 표본 재최적화를 피해
   0.5 를 유지하고 운용 경험 축적 후 재검토 권장. 0.5~999 어디든 무히스테리시스
   대비 압도적 우위라는 사실이 핵심이다.
