## 아이디어

구 `_redistribute_to_cap` 은 "넘은 스타일 축소 -> 전체 재정규화"를 10회 반복했다. 재정규화가 방금 캡에
맞춘 스타일까지 다시 키우므로, 캡에 닿는 스타일이 여럿인 달에는 10회 안에 수렴하지 못하고 캡을 넘긴 채
끝났다. water-filling 은 넘은 스타일을 캡에 고정하고 남은 몫만 나머지 스타일에 현재 비율대로 나눈다.
고정 집합은 늘기만 하므로 스타일 수 이내에 끝나고, 캡이 가능한 구성이면 항상 정확히 맞는다.

구현: `service/pipeline/optimization.py:_redistribute_to_cap`. 스위치 없음 (정정). 캡이 걸리지 않는
달의 비중은 구 구현과 같다.
