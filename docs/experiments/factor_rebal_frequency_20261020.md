- 판정: **기각 (production 은 현행 매달 학습 유지)** — 6개월의 우위는 주변 주기(3·12개월)에서 재현되지 않는 단일 고점이고,
  전반부(2018~2022)에만 존재. 대신 **공식 성과 수치(Sharpe 0.68, config 주석 0.661)는 실제 배포 방식이 아님**을 확인

## 계기

2026-09~10 MXWO 실측 부진 분석 중, 9월 백테스트 포트(+3bp)와 실제 배포 8/31 북(+15bp)의 괴리를 발견.
수익률 출처(DB 월수익률 vs bbg 일별)는 일치했고 **포트 자체가 달랐다** (팩터 비중 겹침 65%).

## 아이디어

walk-forward 엔진은 Tier 1 **규칙**(팩터별 섹터 제외, 분위별 L/N/S 라벨, 유효 팩터 필터 — `filter_and_label_factors`)을
`--factor-rebal-months`(CLI 기본 6) 마다 학습하고, Tier 2 선정·가중은 매달(MXWO `weight_rebal_months=1`) 한다.
production `mp` 는 규칙까지 **매달** 학습한다. 즉 지금까지의 공식 백테스트는 배포 방식과 규칙 주기만 다르다.

- A (현행 production 과 동일): 규칙 매달 학습 (`--factor-rebal-months 1`)
- B (공식 백테스트 = 후보): 규칙 6개월 학습 (기본)
- 감도: 2·3·12개월
- 코드 변경 없음 (CLI 인자만) -> byte-diff 대상 없음

### 해석

1. **6개월은 단일 고점**: 2·3개월(0.45·0.47)과 12개월(0.35) 사이에서 6개월만 0.68. 주기에 대한 단조 관계가 없다.
2. **튜닝 편향**: MXWO 스택(IS 48개월, ERC 수축 0.2, TSM 0.2, 히스테리시스 0.25, dedup off, 섹터 숏캡 0.15 등)은 전부
   규칙 6개월 백테스트 위에서 골랐다 (`mxwo_sharpe_ladder_20260729.md`). 튜닝 지점에서만 높고 이웃 설정에서 0.35~0.47 로
   내려오는 모양은 과적합 고점의 전형. **현 스택의 기대 Sharpe 는 규칙 주기와 무관하게 0.4~0.5 수준**으로 보는 것이 보수적.
3. **production 을 6개월로 바꿔도** 이웃 설정 결과로 보아 0.68 이 재현될 근거가 약하고, 최근 4년은 차이가 없다.
   규칙 번들 저장/재사용·월 정렬 구현 부담만 생긴다.
